## Arquitectura propuesta

App Ionic (cámara → base64) → API Gateway (HTTPS, CORS activado) → Lambda (Python 3.12, boto3) → Amazon Rekognition.

Las 3 lambdas:
1. `registrar-rostro`: recibe ID/nombre y foto; usa `IndexFaces` con `ExternalImageId` = ID de la persona.
2. `reconocer-rostro`: recibe una foto; usa `SearchFacesByImage`; devuelve si hay coincidencia, el ID y la similitud.
3. `listar-eliminar-rostros` (o `CompareFaces` entre dos fotos): lambda de apoyo.

Todo en una sola región (propuesta: `us-east-1`). Colección de Rekognition: `rostros-udv`. Rol IAM con `AmazonRekognitionFullAccess` y `AWSLambdaBasicExecutionRole`.

## Código base de `reconocer-rostro`

```python
import boto3, base64, json

rek = boto3.client("rekognition")
COLLECTION = "rostros-udv"

def lambda_handler(event, context):
    body = json.loads(event["body"])
    image_bytes = base64.b64decode(body["image"])
    try:
        res = rek.search_faces_by_image(
            CollectionId=COLLECTION,
            Image={"Bytes": image_bytes},
            FaceMatchThreshold=85,
            MaxFaces=1,
        )
        matches = res["FaceMatches"]
        if not matches:
            result = {"match": False}
        else:
            m = matches[0]
            result = {
                "match": True,
                "id": m["Face"]["ExternalImageId"],
                "similarity": m["Similarity"],
            }
        status = 200
    except Exception as e:
        result, status = {"error": str(e)}, 500
    return {
        "statusCode": status,
        "headers": {"Access-Control-Allow-Origin": "*", "Content-Type": "application/json"},
        "body": json.dumps(result),
    }
```
